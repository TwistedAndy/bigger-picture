TwistedAndy/bigger-picture

A fast, lightweight lightbox for images, video, audio, embeds and HTML. Smooth zoom from the thumbnail and back, deep zoom with responsive images, and no dependencies.

Getting started

Installation

Bigger Picture ships as a UMD bundle for a plain <script> tag, as ES and CommonJS modules for bundlers, and as Svelte source. Every build needs the stylesheet.

Script tag (UMD)

The UMD build exposes a global BiggerPicture function. This page loads the library exactly this way.

HTML
<link rel="stylesheet" href="dist/bigger-picture.css" />
<script src="dist/bigger-picture.umd.js"></script>
<script>
  const bp = BiggerPicture()
</script>

Or load it from jsDelivr straight from GitHub. Pin a tag or a commit instead of @main in production.

HTML
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/TwistedAndy/bigger-picture@main/dist/bigger-picture.css" />
<script src="https://cdn.jsdelivr.net/gh/TwistedAndy/bigger-picture@main/dist/bigger-picture.umd.js"></script>

npm and bundlers

Terminal
npm install @twistedandy/bigger-picture
JavaScript
import BiggerPicture from '@twistedandy/bigger-picture'
import '@twistedandy/bigger-picture/css'

const bp = BiggerPicture()

Svelte

If your app already uses Svelte 4 or 5, import the source components to share the Svelte runtime and get a smaller bundle. Svelte 5 compiles them in legacy mode.

JavaScript
import BiggerPicture from '@twistedandy/bigger-picture/svelte'

Quick start

Create one instance and open it from a click handler. Links to images need nothing else: the type is detected from href, and the image inside the link is used as the thumbnail the gallery zooms from.

HTML
<div class="gallery">
  <a href="canyon.jpg"><img src="canyon-thumb.jpg" alt="Antelope Canyon" /></a>
  <a href="macaw.jpg"><img src="macaw-thumb.jpg" alt="Macaw" /></a>
  <a href="bear.jpg"><img src="bear-thumb.jpg" alt="Bear cub" /></a>
</div>
JavaScript
const bp = BiggerPicture()
const links = document.querySelectorAll('.gallery a')

links.forEach((link) => {
  link.addEventListener('click', (event) => {
    event.preventDefault()
    bp.open({
      items: links,
      el: link,
    })
  })
})

One instance can open any number of galleries, so you rarely need more than one. Pass el to start at the clicked item; the open and close animations then run from that link's image.

Providing items

Each gallery item can come from a link, from data-* attributes, or from a JavaScript object. They can be mixed in one gallery.

SourceHow it worksGood for
LinksOnly href. The type is detected from the URL.Content from a CMS, articles, existing markup.
Data attributesdata-img, data-thumb, data-caption and the other item properties.Galleries with srcset, captions and exact sizes.
ObjectsAn array of objects with the same properties. Any property can be a function.Data from an API, generated galleries.

How the type is chosen

Explicit properties win, in this order: sources (video or audio), iframe, img, html. Without them, link or the element's href is parsed:

URLOpens as
.jpg .jpeg .png .gif .webp .avif .svg .bmp .tiff .icoImage
.mp4 .webm .mov .ogv .mpeg .avi .h264HTML5 video
.mp3 .wav .ogg .oga .m4a .aac .flac .opus .weba .wma .midHTML5 audio
YouTube: watch?v=, youtu.be, shorts/, embed/, playlistsEmbed with autoplay. t=1m30s becomes the start time.
Vimeo, including private links with a hashEmbed with autoplay
SoundCloud tracksSoundCloud player
Google Drive files, Dropbox links, .pdfFull size iframe
Anything elseThe element itself, as HTML

Use the types option to keep only some of them.

Examples

Image gallery

Data attributes give the gallery everything up front: a responsive srcset, a thumbnail to show while loading, and the full resolution so zoom stops at native size. thumbs: true adds a thumbnail strip.

Click an image, then use the arrow keys, the thumbnails, or swipe. Click or scroll to zoom.

HTML
<div id="gallery">
  <a
    href="bear.jpg"
    data-img="bear-1800.jpg 1800w, bear.jpg 3000w"
    data-thumb="bear-thumb.jpg"
    data-alt="Brown bear cub in the grass"
    data-width="3000"
    data-height="2000"
  >
    <img src="bear-thumb.jpg" alt="Brown bear cub in the grass" />
  </a>
  <!-- more links -->
</div>
JavaScript
const bp = BiggerPicture()
const gallery = document.getElementById('gallery')

gallery.addEventListener('click', (event) => {
  const link = event.target.closest('a')
  if (!link) return
  event.preventDefault()
  bp.open({
    items: gallery.querySelectorAll('a'),
    el: link,
    thumbs: true,
  })
})
  • data-width and data-height are the full resolution. Without them, the size is read from the thumbnail and updated once the image loads.
  • The sizes attribute is updated as you zoom, so the browser picks a larger file from srcset only when it is needed.
  • One delegated listener on the container also works for links added later.

Automatic link detection

Point the gallery at ordinary links and it works out what each one is: images, video and audio files, YouTube, Vimeo, SoundCloud, PDF documents and more. This fits content you don't control, such as articles from a CMS.

Every link below is a plain <a href> with no data attributes. Watch the YouTube video from 0:40, the same one through a youtu.be short link, or a Vimeo video. Native files work too: an animated short (.webm) and a live recording (.mp3). There is also a SoundCloud track, a PDF paper and a photo linked from text.

This link is ignored because it doesn't match the selector: providing items.

Thumbnails for YouTube and Vimeo are fetched automatically. Text links zoom from the link itself.

JavaScript
const bp = BiggerPicture()

const selector = [
  'a[href$=".jpg"]', 'a[href$=".png"]', 'a[href$=".webp"]',
  'a[href$=".webm"]', 'a[href$=".mp4"]', 'a[href$=".mp3"]', 'a[href$=".pdf"]',
  'a[href*="youtube.com"]', 'a[href*="youtu.be"]',
  'a[href*="vimeo.com"]', 'a[href*="soundcloud.com"]',
].join(', ')

const article = document.querySelector('article')

article.addEventListener('click', (event) => {
  const link = event.target.closest(selector)
  if (!link) return
  event.preventDefault()
  bp.open({
    items: article.querySelectorAll(selector),
    el: link,
    thumbs: true,
  })
})
  • Query parameters of YouTube and Vimeo links are passed to the player, and t=40s or t=1m30s becomes the start time.
  • A link with an <img> inside uses that image as its thumbnail and copies its object-fit for the animation.
  • A text link to an image uses the full image as its thumbnail. Add data-thumb to avoid loading every full image when the gallery opens.

Items from JavaScript

Pass an array of objects when the data comes from code. Set element on each item so the gallery can zoom from it and back. Any property can be a function that receives the item.

JavaScript
const bp = BiggerPicture()
const buttons = document.querySelectorAll('#photos button')

const photos = [
  { img: 'macaw.jpg', thumb: 'macaw-thumb.jpg', alt: 'Macaw', width: 1667, height: 2500 },
  { img: 'leopards.jpg', thumb: 'leopards-thumb.jpg', alt: 'Leopards', width: 2400, height: 2400 },
  // ...
]

const items = photos.map((photo, index) => ({
  ...photo,
  element: buttons[index],
  caption: (item) => `${item.alt}, ${item.width} × ${item.height}`,
}))

buttons.forEach((button) => {
  button.addEventListener('click', () => {
    bp.open({ items, el: button, thumbs: true })
  })
})
  • el matches the clicked button against each item's element. Use position instead when there is no element.
  • Use link instead of img, iframe or sources to let the URL decide the type, as in link detection.
  • Strings with numbers are fine for width and height, so values from dataset can be passed as they are.

Video and audio

Native video and audio use sources: one <source> per entry, so the browser picks the first format it supports. Add subtitles with tracks and extra attributes with attr.

Video · 7 subtitle tracks Audio · looped
HTML
<a
  href="agent-327.webm"
  data-sources='[{"src": "agent-327.webm", "type": "video/webm"}, {"src": "agent-327.mp4", "type": "video/mp4"}]'
  data-tracks='[{"label": "English", "kind": "subtitles", "srclang": "en", "src": "en.vtt", "default": "true"}]'
  data-thumb="agent-327.jpg"
  data-width="1920"
  data-height="804"
>
  <img src="agent-327.jpg" alt="Agent 327" />
</a>

<a
  href="live.mp3"
  data-sources='[{"src": "live.mp3", "type": "audio/mpeg"}]'
  data-attr='{"loop": true}'
  data-thumb="cover.webp"
  data-width="800"
  data-height="800"
>
  <img src="cover.webp" alt="Live recording" />
</a>
JavaScript
document.querySelectorAll('.media').forEach((link) => {
  link.addEventListener('click', (event) => {
    event.preventDefault()
    bp.open({ items: link, el: link })
  })
})
  • An audio source creates an <audio> element over the thumbnail; anything else creates a <video>. Both start with controls, autoplay and playsinline.
  • Passing a single element as items opens it on its own.
  • A bare link to a .mp4 or .mp3 file works too, see link detection.

Embeds and iframes

YouTube, Vimeo and SoundCloud links become players with autoplay. Anything else that can be framed works through iframe: maps, documents, demos, your own pages.

YouTube Vimeo SoundCloud OpenStreetMapdata-iframe
HTML
<!-- detected from the link, the thumbnail comes from the image inside -->
<a href="https://www.youtube.com/watch?v=286jXjwdst0" data-title="Uebok">
  <img src="uebok.jpg" alt="Uebok" />
</a>

<!-- any page that allows framing -->
<a
  href="https://www.openstreetmap.org/#map=13/50.4501/30.5234"
  data-iframe="https://www.openstreetmap.org/export/embed.html?bbox=30.43,50.40,30.63,50.50"
  data-title="Map of Kyiv"
  data-width="1600"
  data-height="1000"
>OpenStreetMap</a>
  • data-title sets the iframe's title for screen readers.
  • Without a thumbnail image, YouTube and Vimeo previews are loaded from i.ytimg.com and vumbnail.com.
  • Iframes default to 1920 × 1080, scaled to fit. Set data-width and data-height for another aspect ratio; PDF, Drive and Dropbox fill the screen.
  • Add attributes such as referrerpolicy or allow with data-attr.

Cropped and letterboxed thumbnails

Thumbnails are often cropped with object-fit: cover or letterboxed with contain. The gallery reads the thumbnail's object-fit and animates the crop, so the full image unfolds from exactly what was visible.

object-fit: cover

object-fit: contain

Open an image and close it again to compare the two animations.

CSS
.thumbs a {
  aspect-ratio: 1;
}

.thumbs img {
  width: 100%;
  height: 100%;
  object-fit: cover; /* or contain */
}

To force a mode, set fit on the item (data-fit) to cover, contain or fill. When the thumbnail's shape matches the image, the default fill is all you need.

Responsive images and deep zoom

Give img a srcset and the gallery starts with the smallest file that looks sharp, then switches to larger files only as you zoom in. Raise maxZoom for maps and detailed artwork.

Zoom in on the map and watch the Network panel: the 6000px file loads only when you need it.

HTML
<a
  href="map-2500.webp"
  data-img="map-1300.webp 1300w, map-2500.webp 2500w, map-6000.webp 6000w"
  data-thumb="map-1300.webp"
  data-max-zoom="50"
  data-width="6000"
  data-height="3376"
  data-alt="Map of Exandria"
>
  <img src="map-1300.webp" alt="Map of Exandria" />
</a>
  • maxZoom is a multiple of the starting size, and zoom never goes past data-width. Set it per item with data-max-zoom or for the whole gallery in the options.
  • Set the sizes option to take control of the sizes attribute yourself.

Captions

Add data-caption (or caption) to show text under the item. It can contain HTML such as links. Captions hide while an image is zoomed.

HTML
<a
  href="bear.jpg"
  data-img="bear-1800.jpg 1800w, bear.jpg 3000w"
  data-caption="Brown bear cub. Photo by Janko Ferlič on <a href='https://unsplash.com/photos/SDivo1PTBDs'>Unsplash</a>"
>
  <img src="bear-thumb.jpg" alt="Brown bear cub" />
</a>
CSS
.bp-caption {
  font-size: 15px;
  background: rgba(0, 0, 0, 0.6);
}

Captions are inserted as HTML, so escape text that comes from users before passing it in.

HTML content

Any HTML can be shown in the gallery: dialogs, cards, slides, or a whole component mounted in onOpen. Size HTML items with CSS; width and height are not used.

JavaScript
// a string of HTML
bp.open({
  el: button,
  items: [{ html: document.getElementById('dialog-template').innerHTML, element: button }],
  onOpen(container) {
    container.querySelectorAll('.message_box .button').forEach((btn) => {
      btn.addEventListener('click', bp.close)
    })
  },
})

// several HTML items make a gallery of slides
bp.open({ items: slides.map((html) => ({ html, element: button })) })

// an empty item, filled in onOpen
bp.open({
  el: button,
  items: [{ html: '', element: button }],
  onOpen(container) {
    mountParallax(container.querySelector('.bp-html'))
  },
})
  • When an element has no img, sources, iframe or html and its link isn't recognized, the element itself is shown as HTML. Elements without any link are skipped.
  • Several items can share one element; open them with position instead of el.
  • HTML items zoom from their element too; the size is taken from the rendered content.

Inline gallery

Mount an instance inside any element to embed the gallery in the page. Inline galleries don't lock scrolling or listen to the keyboard. Here, clicking the image opens it full screen, and the two instances stay in sync.

HTML
<div id="inline-gallery" style="position: relative; aspect-ratio: 3 / 2"></div>
JavaScript
const wrap = document.getElementById('inline-gallery')
const inline = BiggerPicture({ target: wrap })

inline.open({
  items,
  inline: true,
  noClose: true,
  thumbs: true,
  onImageClick(container, activeItem) {
    // open the same items full screen, zooming from the inline image
    const element = container.querySelector('.bp-img:last-child')
    bp.open({
      items: items.map((item) => ({ ...item, element })),
      position: activeItem.i,
      onUpdate: (_, item) => inline.setPosition(item.i),
    })
    return true // prevents the inline zoom
  },
})
  • The target needs position: relative and a height.
  • noClose hides the close button. The close method still works.
  • Open the gallery when it scrolls into view with an IntersectionObserver to avoid loading images early.

Controlling the gallery

Every instance can be driven from code with next, prev, setPosition and close, and reports what happens through callbacks. The log below shows the callbacks as you use the gallery.

    JavaScript
    let activeItem

const bp = BiggerPicture({ target: wrap })

bp.open({
  items,
  inline: true,
  onOpen: (container, item) => (activeItem = item),
  onUpdate: (container, item) => (activeItem = item),
  onResize: (container, item) => log('onResize'),
  onImageClick: (container, item) => log('onImageClick'),
  onClose: () => log('onClose'),
  onClosed: () => log('onClosed'),
})

nextButton.onclick = () => bp.next()
prevButton.onclick = () => bp.prev()
firstButton.onclick = () => bp.setPosition(0)
zoomButton.onclick = () => (activeItem.zoom = !activeItem.zoom)
closeButton.onclick = () => bp.close()

    activeItem is the normalized item: i is its index, type is image, video, iframe or html, and images have a zoom property you can read and set.

    Filtering by type

    types keeps only the item types you list. Point every gallery on a page at the same links and let each one decide what it shows.

    videoiframeiframe

    Dimmed items are excluded by the current filter.

    JavaScript
    bp.open({
  items: grid.querySelectorAll('a'),
  el: link,
  types: ['video', 'iframe'],
})

    Positions refer to the filtered list, so el, the counter and the thumbnails always agree. An excluded el opens the first remaining item.

    Dialog mode

    With dialog: true the gallery is a <dialog> opened with showModal(). It joins the browser's top layer, so it shows above other modal dialogs, makes the rest of the page inert, and needs no z-index.

    Uncheck the option and open an image again: a regular gallery is drawn under the modal, because the modal sits in the top layer.

    JavaScript
    const bp = BiggerPicture({
  target: document.body,
  dialog: true,
})
    • The backdrop is the dialog's ::backdrop, faded in and out with the gallery.
    • Inline galleries open with show(), so they stay in the page flow.

    Reference

    Options

    Options are passed to open(). The two initialization options go to BiggerPicture().

    Initialization

    OptionTypeDefaultDescription
    targetHTMLElementdocument.bodyElement the gallery is mounted in. Calling BiggerPicture() without options mounts it in document.body.
    dialogbooleanfalseRender as a <dialog> in the top layer. See dialog mode.

    open(options)

    OptionTypeDefaultDescription
    itemsElement, NodeList, ArrayThe items to show: elements with data attributes or links, or an array of objects. Required.
    elElementStart at the item whose element is el. The open and close animations run from that element.
    positionnumber0Start at this index of items. Ignored when el is set.
    typesstring, string[]Keep only these types: image, video, iframe, html.
    thumbsbooleanfalseShow a thumbnail strip when there is more than one item.
    scalenumber1Size of the item relative to the available space.
    maxZoomnumber10Maximum zoom as a multiple of the starting size, never beyond the full resolution.
    sizesstringFixed sizes attribute for srcset images instead of the automatic one.
    introstringfadeup replaces the zoom from the thumbnail with a fade.
    inlinebooleanfalseInline gallery: no scroll lock and no keyboard handling.
    noClosebooleanfalseHide the close button and ignore Escape, backdrop clicks and swipes.
    noPinchfunctionReturn a truthy value to disable pinch zoom. Receives container.
    focusWrapElementcontainerElement that keeps focus inside it on Tab.

    Callbacks

    CallbackArgumentsCalled
    onOpencontainer, activeItemBefore the intro animation.
    onUpdatecontainer, activeItemAfter the active item changes.
    onResizecontainer, activeItemWhen the gallery (not the window) changes size.
    onImageClickcontainer, activeItemWhen an image is clicked. Return a truthy value to prevent zooming.
    onErrorcontainer, activeItem, eventWhen an image, video or audio source fails to load.
    onClosecontainer, activeItemBefore the outro animation.
    onClosedAfter the gallery is removed from the page.

    Item properties

    Set these as data-* attributes on elements or as properties on objects. On objects, img, thumb, link, alt, caption, sources, iframe, html, attr and fit can also be functions that receive the item and return the value.

    PropertyAttributeTypeDescription
    imgdata-imgstringImage URL or a srcset value.
    thumbdata-thumbstring, HTMLImageElementImage shown while loading and in the thumbnail strip. Defaults to the <img> inside the element.
    linkdata-linkstringURL whose type is detected automatically. Defaults to the element's href.
    altdata-altstringAlternative text for images.
    captiondata-captionstringCaption, may contain HTML.
    widthdata-widthnumber, stringFull width in pixels. Default 1920.
    heightdata-heightnumber, stringFull height in pixels. Default 1080.
    sourcesdata-sourcesobject[], JSONVideo or audio sources. Each object becomes a <source> with those attributes.
    tracksdata-tracksobject[], JSONText tracks for video. Each object becomes a <track>.
    iframedata-iframestringURL to show in an iframe.
    titledata-titlestringTitle of the iframe.
    htmldata-htmlstringHTML to show. Size it with CSS.
    attrdata-attrobject, JSONExtra attributes for the <img>, <video>, <audio> or <iframe>.
    fitdata-fitstringcover, contain or fill for the open and close animation. Defaults to the thumbnail's object-fit.
    maxZoomdata-max-zoomnumberOverrides the maxZoom option for this item.
    elementElementElement the item animates from and back to. Set automatically for elements.

    Methods and properties

    BiggerPicture() returns an instance. It can be opened again with new items after it closes.

    MemberDescription
    open(options)Opens the gallery with the given options.
    close()Closes the gallery with the outro animation. Works even with noClose.
    next()Shows the next item, wrapping around at the end.
    prev()Shows the previous item, wrapping around at the start.
    setPosition(index)Shows the item at index of the filtered list.
    itemsThe normalized items of the open gallery, or null when closed.
    targetThe element the instance is mounted in.

    Normalized items

    Callbacks and items give you normalized objects with every property above, plus i (index in the gallery), type and, for images, a zoom property that reads and sets the zoom state.

    Keyboard, mouse and touch

    Full screen galleries handle these out of the box. Inline galleries handle the pointer and touch gestures but leave the keyboard to the page.

    InputAction
    EscClose (unless noClose)
    ← →Previous and next item
    + -Zoom an image in and out
    Arrow keys while zoomedMove the zoomed image
    TabMoves focus between the gallery controls only
    Click or tap an imageZoom in to full size, click again to zoom out
    Mouse wheel, pinchZoom in and out around the pointer
    DragMove a zoomed image; flicks keep their momentum
    Swipe left or rightPrevious and next item
    Swipe up, click the backdropClose
